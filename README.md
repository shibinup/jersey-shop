(# 🏆 Jersey Hub

A modern full-stack football jersey e-commerce website built with **Next.js** and **Firebase**. This project was created to learn and explore the capabilities of Next.js and Firebase while building a real-world application.

> 🚀 This was my first project using both **Next.js** and **Firebase**, and it helped me understand server-side rendering, routing, authentication, Firestore, and modern React development.

---

## 📌 Features

- 🔐 Google Authentication with Firebase
- 🛒 Shopping Cart
- 👤 Guest Cart Support
- 🔄 Cart Merge After Login
- 🔍 Product Search
- 🎯 Category Filtering
- 📱 Fully Responsive Design
- ⚡ Fast Performance with Next.js
- 🔥 Firestore Database
- 🎨 Modern UI with Tailwind CSS

---

## 🛠️ Tech Stack

### Frontend
- Next.js
- React.js
- Tailwind CSS

### Backend & Database
- Firebase Authentication
- Cloud Firestore
